# SUBASHTI 5-Minute Birthday Surprise

## Folder structure

birthday-surprise/
├── index.html
├── style.css
├── script.js
├── birthday.mp3
└── images/
    ├── photo1.jpg
    ├── photo2.jpg
    ├── ...
    └── photo13.jpg

## Important
- Rename the birthday song exactly to `birthday.mp3`.
- Put all 13 photos in `images/`.
- Names must be exactly `photo1.jpg` through `photo13.jpg`.
- Open `index.html` with Live Server in VS Code.
- For GitHub Pages, upload the same structure and commit all files.
- The page uses only HTML, CSS and vanilla JavaScript; no build step is required.
